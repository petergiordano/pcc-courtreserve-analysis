## Data Quality Notes

### What Was Wrong

**Issue:** Check-ins table counted full program price on every attendance

**Example:**
- Customer pays $660 for 6-week program (one payment)
- Attends 6 sessions
- Database records: 6 check-ins × $660 = $3,960
- **Actual payment:** $660

**Result:** Revenue inflated by ~18x for program participants

### What Was Fixed

**Solution:** Filter out `registration_type='Full'` from pay-per-use calculations

```python
# OLD (wrong):
pay_per_use = checkins[checkins['membership_name'].contains('Non-Member')]

# NEW (correct):
pay_per_use = checkins[
    (checkins['membership_name'].contains('Non-Member')) &
    (checkins['registration_type'] != 'Full')  # Exclude programs
]
```

**Verification:** Cross-referenced with transactions table for actual payments
